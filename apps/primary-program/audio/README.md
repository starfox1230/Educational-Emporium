# Song files

Put the eight `.m4a` files in this folder using these exact names. The player loads each file from this folder and plays selected songs in this order, then loops.

1. `01-choose-to-serve-the-lord.m4a`
2. `02-ill-walk-with-you.m4a`
3. `03-holy-places.m4a`
4. `04-im-trying-to-be-like-jesus.m4a`
5. `05-i-feel-my-saviors-love.m4a`
6. `06-my-heavenly-father-loves-me.m4a`
7. `07-kindness-begins-with-me.m4a`
8. `08-i-will-walk-with-jesus.m4a`

The player’s filenames are listed in `../app.js` in the `tracks` array. If you use different filenames, update the matching `src` value there. This folder intentionally contains no audio until you add it.
